# Lab 08 — tools

This lab uses the following, all within Topic 02 (Tools and Skills):

- **Claude Cowork**
- **Agent Skills**
- **/skill-creator**

## No connector needed

This lab works entirely on files you attach to the chat, so there is no
connector to enable. Claude reads the template, restyles the deck and hands the
result back as a download.

## Running a slash command

`/skill-creator` is typed into the composer, not written inside a longer prompt.
Start typing `/` and it appears in the list — select it, then describe the skill
you want saved. The skill you create here is run the same way, as `/brand-deck`.

## Depends on Lab 6

This lab restyles the PowerPoint you downloaded in Lab 6 — attach it to the chat
before you start. Run Lab 6 first, or use another presentation you are happy to
have restyled.

## The template

`meridian-brand-template.pptx` in `mock-data/` is Meridian's house template: a
title slide, a content slide and a chart slide, in the firm's colours and fonts.
It is a style reference, not a Meridian report — the content on it is filler.
Claude learns the house style by reading it, which is why you never type a
colour value in this lab. The same rules are written down in the brand
guidelines you load into the Claude Project in Lab 9.
