# Lab 10 checklist — Add the Productivity Plugin

- [ ] Open the Plugins panel and switch to the Discover tab.
- [ ] Find the Productivity plugin from Anthropic and click Add.
- [ ] Check Your plugins to confirm it installed.
- [ ] Type `/` in the composer and find the new `/productivity:` commands.
- [ ] Open the Meridian project from Lab 9 and run `/productivity:start` there.
- [ ] Answer whatever it asks and let it create the task list.
- [ ] Open `TASKS.md` in the project folder and read the sections.
- [ ] Add the follow-ups this course actually produced.
- [ ] Run `/productivity:update` and see it triage.
- [ ] Note what the plugin could also connect to.

## Done when

- [ ] The Productivity plugin appears under Your plugins, and typing `/` lists its `/productivity:` commands alongside the `/daily-brief` and `/brand-deck` skills you wrote. A `TASKS.md` file exists in the Meridian project folder with Active, Waiting On, Someday and Done sections, and it holds at least the three Meridian follow-ups: the Q4 Advisory target discrepancy, the board deck review, and the daily-brief draft check.
