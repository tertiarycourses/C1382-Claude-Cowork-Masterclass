# Lab 02 checklist — Your First Live Artefact

- [ ] Start a new Cowork session — this lab needs no files.
- [ ] Paste the lab prompt into the composer and send it.
- [ ] Try the converter: change the amount and switch the currencies.
- [ ] Check the rate Claude found against a search for "1 USD to SGD".
- [ ] Open the downloaded HTML file in your browser and click Refresh.
- [ ] Ask for one refinement in plain English, for example: Add a thousands separator to the result.
- [ ] Save the artefact so it appears in your sidebar.
- [ ] Download a copy of the artefact to your lab folder.

## Done when

- [ ] The artefact converts S$10,000 to USD using the rate Claude looked up, and shows a "Rates as at …" line with today's date. The downloaded HTML file opens in your browser, fetches rates itself and updates them when you click Refresh. The artefact appears in your sidebar after saving and still works when reopened.
