# Lab 06 checklist — Build the Meridian Claude Project

- [ ] In Cowork, choose New project, then Start from scratch.
- [ ] In the Start a new project dialog, type the Name: Meridian Finance Reporting.
- [ ] Paste the lab prompt's rules into the Instructions box.
- [ ] Under Add files, drop in the Meridian finance data and the brand guidelines.
- [ ] Set Choose project location to where you want the folder to live, then click Create.
- [ ] Add the daily-brief skill from Lab 5 to the project.
- [ ] Open the project folder on your computer and confirm the files are really there.
- [ ] Save the FY2026 dashboard into the project so it sits with the data it reports on.
- [ ] Start a fresh chat in the project and ask for a one-paragraph Q4 summary.
- [ ] Confirm the folder holds the data, instructions, skill and dashboard, ready to share.

## Done when

- [ ] A Meridian Finance Reporting project exists, backed by a folder containing the finance data and brand guidelines, with project instructions set, the daily-brief skill available and the dashboard saved. A brand-new chat in the project produces a Q4 summary in SGD with the correct header and footer without you attaching a file or restating a single rule.
