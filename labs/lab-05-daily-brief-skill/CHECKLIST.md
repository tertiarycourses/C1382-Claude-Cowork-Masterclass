# Lab 05 checklist — Build a /daily-brief Skill

- [ ] Make sure the Drive and Gmail connectors from Labs 3 and 4 are still enabled.
- [ ] Paste the lab prompt into Cowork.
- [ ] Read the SKILL.md Claude produces, starting with the description line.
- [ ] Check each of the three sections is there, with its fallback wording.
- [ ] Confirm the skill drafts only and never sends — ask for a correction if not.
- [ ] Save the skill, then run it by name to see the briefing.
- [ ] Run it a second time and confirm the format is identical.

## Done when

- [ ] Running the skill produces a briefing with all three sections — Drive changes, desks behind target, emails needing a reply — using the plain fallback wording where a section is empty, ending with a single attention line, with all money in SGD and no email sent.
