# Finance Cowork lab boundary

Use only the fictional workbook in this lab. Do not connect a real finance drive or paste credentials into a prompt. Work from a copy. Keep raw input unchanged. Approved rows only count in the report; duplicate Document IDs count once. Any discrepancy is an exception, never silently corrected. Do not send externally until a human approves totals, recipient and exact file/version.

## Method
1. Inventory all source rows and retain original data.
2. Exclude pending rows and later occurrences of duplicate Document IDs.
3. Compute revenue as sum of positive eligible amounts; expenses as absolute sum of negative eligible amounts; net as revenue minus expenses.
4. Record every exclusion and source path.
5. Save a formula-driven Excel workbook and pause for human reconciliation before delivery.
