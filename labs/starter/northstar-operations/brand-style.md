# Northstar Management-Pack Style

- Voice: direct, calm, specific, and evidence-led.
- Use short headings that state the message rather than naming a generic topic.
- Prefer one main idea per slide and no more than four concise supporting points.
- Use navy for headings, teal for positive or on-target signals, amber for watch items, and red only for target exceptions.
- Keep tables readable at normal zoom. Use units and reporting period in headers.
- Do not use decorative stock imagery or invented logos.
- Use `OWNER TO VERIFY` exactly for an unresolved business claim.
- End with decisions, owners, and next checks rather than a generic conclusion.
